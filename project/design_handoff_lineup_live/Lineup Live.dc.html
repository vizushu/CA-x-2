Installable PWA

Put it on your phone

  1. 01Host this folder on any HTTPS static host: Netlify, Vercel, Cloudflare Pages or GitHub Pages.
  2. 02Open it on your phone. Below 600 px wide it drops this frame and runs full-screen.
  3. 03Install. iPhone: Share → Add to Home Screen. Android: ⋮ → Install app.
  4. 04Live traffic: open Sources & settings and paste a TomTom or Mapbox key.

Offline, the shell and the last forecast load from cache with their timestamps. Cams need a signal.
